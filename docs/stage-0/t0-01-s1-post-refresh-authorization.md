# T0-01 S1 刷新后只读观察授权包

## 1. 决策目的

D0-06 要求在与 `V02-R01` 相同的静态 DOM 生命周期中重复读取，但页面在 R02 运行前已经刷新，因此 D0-06 已熔断且未执行。刷新后的页面属于新的 DOM 生命周期，不能继续沿用原静态重复读取编号或额度。

本授权包申请使用同一份专用、非敏感、可丢弃的 S1 合成会话，对当前刷新后的已完成页面执行一次前瞻性只读观察，登记为 `T0-01-S1-POSTREFRESH-R01`。目标是验证页面刷新后探针能否重新识别相同的脱敏结构与完成候选，不验证真实来源 ID、消息身份或定位句柄跨刷新稳定性。

## 2. 既有未授权输出的处理

操作人在 D0-06 熔断后曾转交一份刷新后输出。该输出虽然经过会话内只读检查并呈现脱敏结构，但产生时没有有效运行授权，因此：

- 不追溯补授权。
- 不登记为 R02、POSTREFRESH-R01 或其他正式证据。
- 不复制到项目 fixture、证据目录、日志或 Git 历史。
- 不用它替代本授权包批准后的前瞻性运行。

| 项目 | 限定范围 |
|---|---|
| 决策编号 | `D0-07` |
| 目标页面 | 原 S1 专用、非敏感、可丢弃的合成会话；当前刷新后的已完成页面 |
| 探针版本 | `0.2.0`，schema `2` |
| 探针 SHA-256 | `5B4B890B5DC384A14F3652DDADF951576A86C3BB3AE520C2A7D67CB5D966E1DB` |

| 页面动作 | 仅人工加载获批探针、确认版本、调用一次 `run()`、预览并转交脱敏 JSON、调用 `dispose()` |
| 数据输出 | 仅探针生成的脱敏 schema 2 JSON |
| 授权有效期 | 一次结果取得，或页面再次刷新/关闭/切换，或任一熔断条件触发后立即失效 |

## 4. 允许动作

1. 人工确认当前仍是原 S1 专用测试会话，页面中仍为 3 个已完成 Question + Answer Turn。
2. 页面刷新会清除临时全局对象时，重新人工加载项目中 SHA-256 与本文件一致的探针源码。
3. 确认 `AICMReadonlyProbe.version` 为 `0.2.0`。
4. 手动调用一次 `run()`，预览后转交完整脱敏 schema 2 JSON。
5. 转交后立即调用 `dispose()`，停止本次操作。

## 5. 明确禁止

- 不把 D0-06 熔断后的既有输出追溯登记为正式证据。
- 不再次刷新、关闭或切换会话，不新建标签页，不主动制造 DOM 变化。
- 不发送、编辑、停止、重试、重新生成、分支或删除消息。
- 不点击复制、反馈或其他响应控件；探针只观察固定候选是否存在。
- 不读取网络、Cookie、令牌、账户信息、浏览历史或其他标签页。
- 不使用网络请求、本地存储、下载或剪贴板能力。
- 不保存正文、真实来源 ID、属性原值、URL 或 DOM 片段。
- 不运行 S2/S3，不追加第二次运行，不因结果不符合预期而补测。

## 6. 熔断与异常处理

出现以下任一情况时不得运行或立即停止；页面仍可操作时调用 `dispose()`，页面已经关闭或再次刷新时确认临时对象已随页面生命周期清除：

1. 当前页面不是原 S1 专用合成会话。
2. 页面在本授权批准后再次刷新、关闭、切换或新增消息。
3. 探针版本或 SHA-256 不匹配。
4. 输出包含正文、真实 ID/URL、属性原值、DOM 片段或未定义字段。
5. 页面结构不再是 6 条消息或出现非预期账户/隐私内容。
6. 需要点击页面控件、读取网络或执行其他未授权动作才能继续。

异常结果即使为 `unconfirmed`、`streaming-signal`、`conflicting-signals` 或结构错误，也只能按事实转交一次，不得通过重新运行挑选结果。

## 7. 验收与比较口径

批准后的 `POSTREFRESH-R01` 单独形成证据，并与刷新前的 `V02-R01` 做限定比较：

1. 校验 schema、探针版本、消息数量、角色交替、连续序号和 summary 内部一致性。
2. 校验 Assistant 的状态候选、`ariaBusyTrue` 和固定完成操作类别。
3. 删除唯一允许变化的 `capturedAt` 后比较两份完整 JSON 值树；任何其他差异均如实登记，不静默归一化。
4. 只允许把用户粘贴中的 HTML 空格实体转换为普通 JSON 格式空白，不改变任何数据值。
5. 新结果须通过 SHA-256、禁止内容扫描、结构断言和 QSR 独立复核。

若两份结果一致，只能得出“在用户报告的一次页面刷新后，探针重新识别出的脱敏结构与完成候选保持一致”。由于探针不保存真实 ID、属性原值或定位句柄，本结果不能满足 T0-02 的跨刷新稳定身份验收，也不能证明 DOM 选择器长期稳定。
