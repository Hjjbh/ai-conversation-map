# T0-05 隐私、权限与探针边界

## 1. 文档状态与适用范围

- 阶段：阶段 0 技术探针。
- 任务：T0-05“隐私、权限与探针边界”的准备与边界定义。
- 主责：QSR。
- 复核：TL。
- 最终放行：PO。
- 放行记录：PO 已于 2026-09-06 批准 `00-kickoff-review.md` 第 5 节推荐决策包；状态变更分支探针与数据外发保持关闭。
- 本文只定义探针和后续首版实现必须遵守的边界，不代表任何浏览器权限、数据外发、自动操作或正式功能已经获批。
- 阶段 0 默认采用本地、最小、可撤销的验证方式。除用户已打开并明确纳入探针的 ChatGPT 页面外，不扩大访问范围。

## 2. 基本原则

1. ChatGPT 原始会话是唯一事实源；插件只读取必要页面事实并生成可重建投影。
2. 本地优先。除 ChatGPT 页面本身外，不向任何服务器发送聊天内容、来源标识或诊断数据。
3. 只采集完成当前探针所必需的数据；先验证低敏感信息，无法满足目标时才提出范围变更申请。
4. 页面内容全部视为不可信输入；不执行其中的脚本、事件处理器或未知 URL scheme。
5. 只读探针与可能改变平台状态的探针严格分开。未经逐项批准，不以“技术验证”为由执行发送、编辑、重试、分支或删除。
6. 低置信度不得转化为高确定性结果：不覆盖稳定映射、不静默错绑、不伪造定位成功或真实分支。
7. 所有导出、复制及跨入口通信均遵循数据最小化；完整正文和认证信息不得进入普通日志或诊断包。

## 3. 最小权限—用例映射

本表是阶段 0 的候选权限边界，不是 Manifest 的最终批准清单。具体权限名称与目标域需在脚手架阶段依据当时浏览器扩展规范和当前 ChatGPT 域名再次核对。

| 权限或访问能力 | 首版/探针用例 | 阶段 0 处理 | 限制与放行条件 |
|---|---|---|---|
| 用户已打开的 ChatGPT 会话页访问 | 识别页面、读取可见会话结构、观察消息变化、定位并高亮来源消息 | 仅限用户明确纳入探针的页面 | 目标域必须精确列举；不得使用覆盖所有网站的通配 host 权限 |
| Content Script | 页面快照、受限 MutationObserver、最小入口及短暂高亮 | 只验证必要注入范围 | 只能运行在已声明的 ChatGPT 会话页；不读取认证信息，不注入完整地图 |
| `storage` 或等价扩展本地存储能力 | 保存设置、脱敏诊断、可重建投影和用户元数据 | 阶段 0 仅允许保存经批准的脱敏产物 | 正文等敏感数据不得写入普通日志；第三方密钥不得进入普通 IndexedDB |
| 标签页激活/查询能力 | 在地图和已打开的原会话间切换 | 仅在双向定位任务确有需要时申请 | 优先采用更窄能力；不得读取无关标签页内容、标题或历史 |
| 新建标签页能力 | 原会话未打开时打开其规范 URL | 状态变更探针中单独确认 | 只能由明确用户动作触发；URL 必须来自已验证的会话引用 |
| 扩展内部消息通信 | Content Script、Background 与扩展页之间传递当前操作所需数据 | 允许定义和验证协议 | 必须校验来源、消息类型、协议版本和 request ID；不得长期保存完整正文 |
| 剪贴板写入 | 用户选择降级等级 D 时复制已确认上下文 | 阶段 0 默认不申请专门权限 | 仅可在明确用户手势后复制预览过的内容；若浏览器要求额外权限，须单独提交 PO |
| `activeTab` | 用户主动触发后临时访问当前页 | 作为常驻 host 权限的潜在替代方案评估 | 不得同时无理由申请范围重叠的广泛权限 |
| `scripting` | 动态注入脚本 | 默认不申请 | 只有静态 Content Script 无法满足已批准用例并有独立证据时才可提案 |
| 网络请求到第三方或自建服务 | 遥测、云同步、远程分析、LLM | 阶段 0 禁止 | 属于数据外发，必须另行完成安全评审并由 PO 明确批准 |
| 浏览历史、下载、书签、Cookie、WebRequest、调试器、认证信息访问 | 无首版用例 | 禁止申请或使用 | 任一新增需求均视为重大权限扩大，需 ADR、QSR/TL 复核和 PO 批准 |

权限评审以“权限—具体用户故事—数据字段—触发方式—保留时间”五项映射为准。任一权限不能完整映射到首版 P0 用例时不得申请。

## 4. 允许与禁止采集的数据

### 4.1 允许采集

仅在用户明确纳入探针的会话中，为完成 T0-01 至 T0-04 所必需时，可处理：

- 页面类型、策略版本、消息数量、角色、逻辑顺序、流式/完成状态。
- 稳定会话 ID、消息 ID、规范会话 URL 或其脱敏表示；原值只允许在当前获批探针的本地内存中短暂使用，落盘前必须替换为一致假值或不可逆映射，完整 URL 查询参数永不落盘。
- 稳定 DOM 属性、可访问性信息、结构关系、选择器命中策略和定位句柄可用性。
- 为验证 Question + Answer 聚合、内容指纹和定位所需的临时文本；优先使用专门构造的非敏感测试会话。
- 未识别节点计数、错误码、耗时、成功/失败结果、解析置信度和能力等级。
- fixture 所需的最小 DOM 结构以及经过脱敏的占位内容。

敏感正文如确需参与本地内存计算，只能用于当前操作，不能因此自动取得日志、导出或长期保留资格。

### 4.2 禁止采集

- 认证 Cookie、访问令牌、会话令牌、CSRF 信息、密码、API key 或其他密钥。
- 浏览器自动填充数据、其他标签页内容、浏览历史、下载记录、书签或非目标站点数据。
- 与投影、定位、身份或分支能力验证无关的页面元素、账户资料、支付或订阅信息。
- 未经授权的网络响应、私有接口数据或通过绕过页面可见能力取得的数据。
- 附件二进制内容；fixture、日志和通用诊断最多保留类型、存在标记及合成/脱敏名称。真实附件名如确为当前获批操作所需，只能在本地内存中瞬时处理，不进入持久证据。
- 完整聊天正文、选中文本或来源 URL 到普通日志、遥测、崩溃上报和通用诊断包。
- 第三方模型请求、远程摘要、云同步或任何形式的隐式数据外发。

## 5. Fixture 脱敏规范

1. 优先使用专门构造、无个人信息和无商业秘密的测试会话生成 fixture。
2. fixture 只保留复现结构差异所需的最小 DOM 子树，删除脚本、样式、网络端点、隐藏账户区域和无关页面内容。
3. 问题、回答、选中文本、标题、附件名等正文统一替换为确定性占位符；需验证长度、代码块、多段回答等特征时，以合成内容保留等价结构。
4. 会话 ID、消息 ID、URL 参数和其他稳定标识使用一致的假值或加盐不可逆映射；同一 fixture 内保持引用关系，不保留原值。
5. 删除姓名、邮箱、电话、地址、组织名、账号、订单号、密钥及可组合重识别信息。
6. 保留角色、顺序、状态、必要属性名和结构层级；属性值若可能包含用户或账户信息必须替换。
7. fixture 文件名不得包含会话标题、用户名、真实 ID 或正文片段。
8. 生成后执行人工复核和敏感模式扫描；复核者不得仅依赖自动替换结果。
9. 无法可靠脱敏的样本不得进入仓库、任务附件或共享诊断包，只能记录抽象结构和复现步骤。
10. 内容指纹属于敏感内容派生数据：不得使用无盐正文直接哈希，不得进入普通日志或共享报告；必须带策略版本、限定本地用途，并遵守经批准的清除与保留周期。
11. 若保存身份迁移候选，只允许包含旧/新脱敏键、证据类型、冲突码、置信度及受影响元数据类别/数量；不得包含正文或原始 DOM，必须支持过期与清除，确认前不得重挂接或删除旧映射。

## 6. 日志、导出与剪贴板边界

### 6.1 日志与诊断

允许字段：时间、探针/Adapter 版本、页面类型、策略编号、计数、布尔能力、错误码、阶段耗时、置信度区间和脱敏关联 ID。内容指纹即使已加盐也不得进入普通日志或共享报告。

禁止字段：完整或连续正文、局部文本锚点原文、选中文本、完整 URL 查询参数、认证信息、密钥、原始 DOM、网络请求头/响应体。

错误对象必须经过白名单序列化；不得直接记录页面对象、异常上下文或任意 payload。开发调试输出在产物提交前清除。

### 6.2 导出

- 默认不导出；导出必须由用户明确发起。
- 导出前展示内容类别、字段和预计范围，并允许取消。
- 默认只导出脱敏诊断，不包含正文、令牌、密钥或完整来源 URL。
- 如未来支持包含正文的导出，必须单独确认、明确标记敏感，并再次获得 PO 对产品策略的批准。
- 导出文件不得自动上传、发送或附加到外部服务。

### 6.3 剪贴板

- 仅在用户明确点击“复制”并确认预览内容后写入。
- 不后台读取剪贴板，不监控剪贴板变化。
- 不复制认证信息、隐藏字段或超出用户选择范围的上下文。
- 分支降级 D 的复制操作不提前创建任何图谱边，也不等同于消息已发送。
- 复制失败必须明确反馈，不得记录待复制正文作为诊断。

## 7. 只读探针与状态变更探针界线

### 7.1 可在已批准范围内开展的只读探针

- 判断当前页面是否为支持的 ChatGPT 会话页。
- 读取目标会话的必要 DOM 结构并生成内存快照。
- 识别消息角色、顺序、状态、稳定属性和可定位信息。
- 观察限定会话容器内的 DOM 变化，并在导航、切换或容器替换时安全重绑/释放 observer。
- 计算脱敏诊断、解析置信度和能力快照。
- 在不改变消息、会话或账户数据的前提下滚动、聚焦和短暂高亮目标消息。
- 检查页面上是否存在用户可见的原生操作入口，但不自动点击会改变平台状态的控件。

### 7.2 视为状态变更的探针

以下任一行为均不属于只读，必须有明确任务步骤、可见影响说明、回滚/清理办法和用户逐次确认；涉及 T0-04、T0-05 最终边界时还需 PO 批准：

- 创建真实分支、新会话或新标签页并触发平台动作。若用户点击的按钮已明确说明“将打开原会话”，该次点击可作为单次新建标签页授权；批量执行、自动重试开页或非前台触发仍需独立确认。
- 编辑旧问题、重试或重新生成回答、继续会话。
- 填充输入框、发送消息、提交表单或模拟用户点击。
- 修改会话标题、归档、删除、分享或调整账户设置。
- 写入剪贴板、导出文件、长期保存正文或用户元数据。
- 调用任何网络接口、远程 Provider、遥测或上传服务。

仅打开浏览器开发工具、读取公开页面结构并不自动授权访问私有接口、认证材料或网络响应内容。自动发送消息在本项目默认禁止；即使技术可行，也不能由探针自行启用。

## 8. 熔断条件与处置

出现以下任一情况立即停止相关探针，不写入新投影或分支结果，保留最后一次有效地图，并向 TL/PO 报告：

1. 发现未经授权读取完整正文或其他敏感数据，或把完整正文、认证信息、密钥记录、导出、外发、写入普通日志/通用诊断。已批准专用测试会话中为当前操作所必需的瞬时本地内存读取不触发本条，但不得因此取得持久化资格。
2. 权限无法映射到已批准的首版用例，或实际访问范围超出声明域和目标页面。
3. 探针需要调用未授权私有接口、绕过登录/限流/付费限制或模拟未确认的用户动作。
4. 页面消息来源、消息类型、协议版本或 request ID 无法校验。
5. 解析置信度低于批准阈值，仍可能覆盖稳定来源映射或写入半可信图。
6. 身份匹配置信度不足，存在用户元数据静默错绑风险。
7. 无法同时验证新目标会话引用与父消息锚点，却可能创建 `branch` 边。
8. 页面内容未经清理即进入富文本渲染，或出现脚本、事件属性、危险/未知 URL scheme 的执行可能。
9. 日志、fixture、诊断、导出或剪贴板中发现未脱敏敏感数据。
10. 状态变更操作缺少明确用户确认、无法安全取消，或其影响/回滚方式不清楚。
11. 插件内删除操作可能影响 ChatGPT 原始会话，或清除范围无法预览和确认。
12. LLM Gateway、遥测、云同步或远程服务被默认启用，或核心流程依赖其可用性。

熔断后只允许执行无状态的证据保全和脱敏记录，不得为了“完成测试”继续扩大权限或数据范围。恢复必须由责任角色提交修正证据，QSR 独立复核，并按风险等级取得 TL 或 PO 批准。

## 9. PO 决策状态

PO 已批准 T0-05 基线、来源标识推荐作用域，以及专用非敏感测试会话的只读探针。以下事项仍需在进入相应操作或实现前单独决定：

- T0-04 真实分支探针的具体状态变更步骤、样本范围及 A/B 等级认定。
- 任何浏览器权限扩大、额外目标域或非用户当前页面的访问。
- 任何消息发送、编辑、重试、重新生成、分支或新会话创建自动化。
- 含正文导出、长期保存正文、数据保留周期或删除策略变化。
- 使用剪贴板专门权限或超出用户即时操作范围的复制能力。
- 任何远程服务、遥测、云同步、LLM Provider、数据外发及相关费用/保留策略。
- 第三方 API key 的存储方式及响应日志策略。
- 无法满足脱敏要求但仍希望使用的真实样本；默认决定应为不使用。

- [ ] 允许与禁止采集的数据已由 ADP、GDE、UIE 按各自接口确认。

## 11. 当前结论

T0-05 推荐决策包已获 PO 放行，但本文仍不包含真实页面验证结果。团队可以对专用、非敏感、可丢弃的测试会话执行已批准的只读探针并生成脱敏 fixture。状态变更探针、权限扩大、正文长期保存、剪贴板写入、远程服务和数据外发继续保持关闭，必须另行批准。
