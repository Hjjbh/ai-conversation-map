# 阶段 0 合成测试会话脚本

本目录提供 S1、S2、S3 三类专用测试会话的合成脚本，用于后续在 ChatGPT 中创建非敏感、可丢弃的测试会话。

## 当前状态

- 已创建：测试脚本与覆盖目标。
- 已创建：专用、非敏感、可丢弃的 S1 ChatGPT 测试会话；不得将其替换为私人或业务会话。
- 尚未创建：S2、S3 ChatGPT 测试会话。
- 已收到：S1 的两次脱敏结构观察 JSON；不含正文、标识值、URL 或 DOM 片段，且不等同于 DOM fixture。
- 尚未采集：原始 DOM、来源 ID 值、消息 ID 值、URL、项目截图或脱敏 DOM fixture。
- 尚未执行：发送、停止生成、编辑、重试、重新生成或分支等页面状态变更。

这些脚本是测试输入设计，不是 T0-01 的真实页面证据，也不能用于判定 Adapter、定位或分支能力已经通过。

## 文件

| 样本 | 文件 | 目标 |
|---|---|---|
| S1 | `S1-basic-linear.md` | 3 Turn 基础线性会话，验证最小 Question + Answer 聚合 |
| S2 | `S2-long-rich.md` | 20 Turn 长会话，覆盖列表、表格、代码块、标题和长文本 |
| S3 | `S3-dynamic-states.md` | 定义流式、完成、中断/错误等动态状态的受控观察脚本 |

## 使用规则

1. 只在专门新建、无私人记忆依赖、可丢弃的 ChatGPT 测试会话中使用。
2. 每个样本使用独立会话，不与私人或业务历史聊天混用。
3. 按编号逐条发送，不临时加入姓名、邮箱、公司、客户、密钥、链接或真实业务数据。
4. 如果 ChatGPT 输出意外包含账号信息、记忆内容或其他敏感信息，立即停止并放弃该样本，不采集 fixture。
5. 真实页面观察前，由 QSR 再次确认采集范围和脱敏步骤。
6. 项目文件只保存本目录中的合成输入与抽象期望；真实来源标识和正文不得写回本目录。

## 证据边界

- “脚本已创建”只证明样本设计就绪。
- “测试会话已创建”需要用户在 ChatGPT 中实际执行并确认。
- “fixture 已验证”需要 ADP 采集最小 DOM、完成脱敏并由 QSR 复核。
- S3 中停止生成等动作属于页面状态变更；脚本可以预先定义，但执行仍需单独确认。
