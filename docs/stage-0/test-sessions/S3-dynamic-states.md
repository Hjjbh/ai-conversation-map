# S3：动态与变体状态

## 目标

定义用于观察流式、完成、中断/错误状态的合成测试会话。本文只准备脚本，不授权自动发送、停止生成、编辑、重试、重新生成或分支。

## 虚构主题

描述虚构机器人“纸灯”的博物馆夜间巡游。不得加入真实地点、人物、组织或账号信息。

## 场景拆分

### S3-A：流式到完成

预备提示词：

> 请为虚构机器人“纸灯”写一篇约一千二百字的博物馆夜间巡游故事，分成六个带标题的章节，全部使用虚构名称。

计划观察点：

1. 用户手动发送后，在回答仍持续变化时进行只读观察。
2. 记录同一来源消息是否保持稳定身份、内容修订是否单调、是否只更新一个活动 Turn。
3. 等待回答自然完成，再观察状态从 `streaming` 到 `complete`。
4. 不保存实际故事正文，只保存脱敏结构、计数、状态与错误码。

执行状态：未执行。用户发送提示词属于页面状态变更，执行前需确认具体测试会话和操作窗口。

### S3-B：完成回答的重复读取

预备提示词：

> 用四条要点总结虚构机器人“纸灯”的巡游规则，每条不超过二十个汉字。

计划观察点：

1. 等待回答完成。
2. 在不改变会话的情况下重复读取三次。
3. 刷新页面后再次读取。
4. 验证相同消息不重复、状态保持 `complete`、定位句柄可重建。

执行状态：未执行。

### S3-C：用户中断生成

预备提示词：

> 为虚构机器人“纸灯”生成一份包含五十项的夜间巡游检查清单，每项都写检查目的和失败处理。

计划观察点：

1. 用户手动发送。
2. 用户在生成过程中手动点击停止；探针不得代替用户点击。
3. 只读观察回答状态、已生成内容边界和后续稳定性。
4. 验证中断消息不会被错误标记为正常完成，也不会创建额外 Turn。

执行状态：未执行。停止生成是明确状态变更，必须在执行前单独确认。

### S3-D：错误状态

不主动制造网络故障、不修改请求、不使用调试器拦截流量。如果专用测试会话自然出现可见错误，可在已批准范围内只读记录抽象错误状态；否则本项标记为“未观察到”，不能用推测补齐。

执行状态：等待自然样本，不作为强制制造场景。

## 明确排除

- 编辑旧问题。
- 重试或重新生成回答。
- 切换多个回答版本。
- 创建分支或新会话以验证分支。
- 自动填充、自动发送或模拟用户点击。
- 调用私有接口、读取网络响应、Cookie 或令牌。

以上能力需要新的任务步骤和单独批准，不能因本脚本存在而视为已授权。

## 探针期望

- S3-A：同一活动 Answer 在流式期间保持同一来源身份，只增加内容修订。
- S3-B：完成回答重复读取与刷新后幂等。
- S3-C：中断状态可表达且不伪装为 `complete`。
- S3-D：没有自然错误样本时明确记录证据缺口。
- 所有场景的证据不含真实正文、原始 ID、完整 URL 参数或原始 DOM。
