# 阶段 0 正式任务卡

## 通用约束

- 本阶段不生成正式功能代码。
- 真实聊天内容、令牌、Cookie、密钥不得进入项目文件、日志或 fixture。
- fixture 必须使用专门测试内容并完成脱敏。
- 只读观察与会改变会话状态的操作分开授权。
- 每个任务完成后记录实际修改与验证结果；未取得证据不得标记完成。

## T0-01：ChatGPT 页面与消息结构盘点

- 主责：ADP
- 复核：QSR
- 风险：高（宿主页面变化、用户内容）
- 输入：经批准的三类专用测试会话；T0-05 已批准边界
- 输出：脱敏 fixture、结构报告、选择器策略、诊断样例
- 允许：读取用户明确打开的专用测试会话 DOM；保存脱敏后的最小结构
- 禁止：保存真实私人聊天；读取令牌；调用私有接口；执行发送或分支
- 验收：三类样本均能识别会话容器、角色、顺序和回答状态；失败产生结构化诊断；低置信度不覆盖稳定映射
- 当前状态：D0-06 已熔断，R02/R03 均未执行；D0-07 的 `POSTREFRESH-R01` 已执行且一次额度用尽，结构与完成候选同 V02-R01 一致，QSR 复核 PASS；S2/S3 未获运行授权

## T0-02：会话/消息稳定身份验证

- 主责：ADP
- 复核：GDE + QSR
- 风险：高（身份漂移可能错绑元数据）
- 输入：T0-01 fixture 与身份契约
- 输出：身份能力矩阵、稳定性结论、降级和迁移候选规则
- 允许：比较专用测试会话在刷新、流式、编辑/重试后的脱敏结构
- 禁止：在置信度不足时静默认定身份；把 DOM 节点持久化
- 验收：重复快照幂等；流式内容修订不重复建 Turn；键漂移有可解释结果；低置信度进入待确认状态
- 当前状态：契约已完成，已建立 S1 证据边界矩阵；D0-08A 实现级 GDE/QSR PASS；D0-08B 已批准，R01/R02 已完成并登记脱敏证据；稳定 ID、回答版本、幂等修订和跨刷新 locator 仍未确认

## T0-03：双向定位技术验证

- 主责：ADP + UIE
- 复核：GDE + QSR
- 风险：中高（跨标签页、定位错误、权限）
- 输入：稳定来源定位句柄、通信协议草案、已批准最小权限
- 输出：地图到原消息、原消息到地图的验证报告及失败码
- 允许：仅在 D0-09B 获批后，在专用测试会话中一次滚动、视口内视觉确认和短暂高亮
- 禁止：把“请求已发送”视为定位成功；持久化 DOM 引用；自动发送聊天消息
- 验收：覆盖标签页存在/不存在、重载、长会话、会话切换、旧响应晚到与定位失败；结果可诊断
- 当前状态：协议草案与 D0-09A 临时单向定位探针实现已完成；D0-09B 已创建并获 PO 批准；真实环境验证尚未运行

## T0-04：真实分支路径验证

- 主责：ADP
- 复核：TL + QSR
- 最终批准：PO
- 风险：极高（状态变更、分支语义、平台边界）
- 输入：公开能力说明、专用可丢弃测试会话、逐项动作授权
- 输出：A-E 能力等级、目标会话/父锚点证据、ADR-008 更新草案
- 允许：先核对公开资料和可见 UI；状态变更动作须另行明确批准
- 禁止：自动发送；绕过权限；调用未授权私有接口；在目标引用不完整时写入真实 `branch`
- 验收：明确原生分支入口、用户点击要求、新会话引用、父消息锚点、路由行为和失败路径；无法验证时保留“未确认”
- 当前状态：公开能力初步报告已完成，真实页面动作未授权，能力等级保持 `unconfirmed`

## T0-05：隐私、权限与探针边界

- 主责：QSR
- 复核：TL
- 最终批准：PO
- 风险：极高（用户内容、扩展权限）
- 输入：T0-01 至 T0-04 数据和浏览器能力需求
- 输出：权限—用例映射、数据处理清单、脱敏规则、熔断条件、批准项
- 允许：文档分析和权限需求评审
- 禁止：在本任务批准前采集真实会话样本或扩大权限
- 验收：每项权限有首版用例；采集/保存/导出边界清晰；正文与认证信息禁入日志；状态变更动作独立授权
