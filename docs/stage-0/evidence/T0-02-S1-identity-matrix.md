## 4. 身份结论与降级

1. 当前样本只能证明“结构、角色、顺序和有限完成候选可被重复/刷新后重新识别”，不能证明会话或消息身份稳定。
2. `dataMessageId`、`dataTestId` 和角色属性的存在性不是属性值、唯一性或生命周期稳定性的证据；不得升级到 Tier 1/2。
3. 当前不产生可持久化 `sourceConversationKey`、`sourceMessageKey` 或 `locator`。任何未来 Adapter 输出都必须将身份置信度设为 `unknown`，直到取得允许的稳定性证据。
4. 若只能使用角色、序号、邻接或内容相似度，应按 Tier 3/`low` 处理，仅生成诊断或迁移候选，不覆盖稳定映射、不重挂接布局/注释、不创建真实 `branch` 边。
5. 刷新后值树一致不等于 DOM 节点一致，也不等于平台 ID 一致；该比较不能关闭 ID-02 或 T0-02 的跨刷新验收项。
6. 本矩阵不把 D0-06 熔断后的任何输出纳入输入；只使用 V02-R01 和 D0-07 正式归档证据。
