# 阶段 0：ChatGPT 技术探针

## 状态

- 阶段状态：已启动
- 启动日期：2026-09-06
- 产品授权：PO 已授权启动阶段 0
- 当前执行范围：文档、公开资料核对，以及专用非敏感测试会话的只读探针与脱敏 fixture
- 尚未授权：私人/业务历史会话、真实正文或标识持久化、自动编辑/重试/分支/发送消息、数据外发

“阶段已启动”不等于所有探针动作均已批准。任何涉及用户账号、真实会话内容或页面状态变化的动作，必须先通过 T0-05 边界审查并取得对应授权。

## 目标

验证当前 ChatGPT Web 是否能为首版插件提供可靠、合规、可降级的基础能力：

1. 识别会话页与消息结构。
2. 获得可持久或可重建的会话/消息身份。
3. 完成地图与原聊天的双向定位。
4. 确认从任意 Turn 创建真实分支的可用路径与限制。
5. 锁定首版最小权限、隐私和证据处理边界。

## 阶段门禁

执行顺序：

1. 先完成任务卡、T0-05 边界和各模块契约草案。
2. TL 进行交叉评审并列出需要 PO 决定的事项。
3. PO 批准样本范围和允许的真实页面动作。
4. 才能采集脱敏 fixture 或执行真实页面探针。
5. T0-01 至 T0-05 证据齐全后进入 T0-06。

## 退出标准

- 至少三类脱敏会话样本完成解析验证。
- 支持样本的 Turn 投影与双向定位达到文档目标。
- 身份漂移、解析低置信度与 DOM 变化具有安全降级证据。
- 真实分支得到 A-E 等级结论；只有可验证平台引用才能成为 `branch`。
- 最小权限、隐私和数据处理清单通过 TL 复核与 PO 批准。
- 全部已知限制、遗留风险和阶段 1 任务进入 T0-06 结论。
